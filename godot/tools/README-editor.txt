Anomaly Editor
==============

The map editor of Anomaly Station: make new stations and change the game's maps, then play them right in the editor (no server needed).

 * Start: the AnomalyEditor program in this folder (Anomaly Editor.app on macOS).
 * File > New map makes a station; File > Open opens one. The game's own maps are in ../maps/map_files.
 * Play (F5) tests the open map as the game would run it.
 * The full guide: https://github.com/Noardewyn/AnomalyStation/blob/main/docs/mapping-guide.md

Keep this folder inside the game's folder: the editor reads the game's assets and maps from there.
Launch problems are the same as the game's: see ../README.txt.
