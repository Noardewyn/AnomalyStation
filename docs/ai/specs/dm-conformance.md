# DM conformance

Status: v1 (wave 1), 2026-10-06; M2 P3 and M2 integration sections added 2026-10-07. One row per settled DM behaviour of the shim (docs/ai/translation-rules.md 0.2): what DM
does, the arbiter that settles it (the BYOND reference first, then OpenDream, then tg's own comments and usage), the
test that pins it, and its status (`pinned`: the test exists and passes; `planned`: the behaviour is decided, the
test is not written yet). Expected values in tests come from these sources, never from running the port.

Each package appends rows **at the end of its own section only**, so parallel packages never touch the same lines:
the contracts package owns "Shim contracts", the values package "Values", the dynamic package "Dynamic calls and
types". BYOND ref anchors are the `<a name=...>` entries of `https://www.byond.com/docs/ref/info.html`.
